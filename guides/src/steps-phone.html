Techstream
Data Acquisition

Vehicle Control History, PCS Freeze Frame Data & camera images
Field steps, at the vehicle · Rev. Sept 2026
Screens after B. Muir / Crash Data Specialists and E. Clarke / CHP MAIT

Before you start

  • Confirm you have lawful authority. Some states require the owner's written consent.
  • Confirm the TIS subscription is active — Professional Diagnostics, not Standard.
  • Retrieve early. VCH records overwrite; every key cycle risks losing data.
  • Have a booster battery. A read can take 1–90 minutes.
  • Photograph the vehicle, VIN plate, odometer and DLC. Note laptop clock vs. actual time.
  • Screen-capture every screen as you go. They cannot be recreated later.

1Check for 12 volts at the battery. Turn the ignition ON — do not start the engine. Connect the VIM to the DLC and to the laptop.

2Launch Techstream. Capture the main screen — software version, remaining subscription time (lower left) and the active VIM in the status bar.

3Click Setup → VIM Select. Choose your interface, click OK, and capture it.

4Click Connect to Vehicle (top of the left panel).

Confirm Division, Model, Year and Engine, set any options the vehicle carries, add a case note in Memo, then Next. Capture this screen — it is your record that the tool was on this VIN.

Connecting manually (D2M)? Type the VIN yourself. Techstream builds the file name from the VIN — blank or wrong gives a mismatch error and a misnamed file.

5At the System Selection Menu, run Health Check to bus-scan the vehicle. Save or print the report and capture the menu as your ECU inventory.

6Open SRS Airbag → Trouble Codes. Save with the disk icon and capture the current, pending and history codes. Then Data List — save and capture that too.

7Back on the System Select tab, click Read Data Function, then choose PCS FFD Retrieval.

Not the Vehicle Control History button. That path gets VCH only. PCS FFD Retrieval gets the VCH and the camera images.

8Read the legal notice, tick OK, then Next. Capture the screen.

9Select Read data, then Next.

Not "Generate csv file". It does not retrieve the image data. CSV output comes later, from the saved file.

10Techstream confirms it will read out Image Data, Operation FFD and Vehicle Control History, and warns the read may take 1–90 minutes. Confirm your power will last, then Next.

11Select the image data to read and check every box offered — five categories on TSS 2.0, one on TSS 1.0. Capture the screen, then Next.

12Check the estimated read time against your power and available time, then Next to start. Do not disturb the laptop or the connection while it runs.

13Capture the completion screen — the most important capture of the retrieval. It reports all three data sets and names the file created.

Image data : N/A means no images were stored. That is a finding, not a failure.

14Click Check. Explorer opens at the save folder — by default C:\Users\Public\Public Documents\ Techstream\PCSdata\. Confirm the .vdas file is there and note the path.

15Still on scene, open the Stored Data tab and review the event list — key cycle, elapsed time, date and time, trigger, odometer, overwrite count. A circle in the Image column marks an event with camera images. Note the key cycles that matter, then export the list with the disk icon.

16Open each relevant event to see its parameters and trigger note, and export it with the disk icon.

The Excel export leaves the camera images behind. Images come out only through the PCS Data Viewer output, done later from the .vdas file — and only while the subscription is still active.

17Copy the .vdas file and every screen capture to external media. Open the copy and check its size. Work the checklist, then exit Techstream, disconnect the VIM and switch the ignition off.

Before you leave

Every item below should be in hand. If one is not applicable, write down why rather than leaving it blank.

1. Retrieval file VIN_…vdas
Where: C:\Users\Public\Public Documents\Techstream\PCSdata\
How: copy to external media — this is the evidence
2. Read Data complete summary
Where: Read Data (IMG_OPE_DDR-010)
How: screen capture — status of all three data sets plus the file name
3. Vehicle Control History event list
Where: Stored Data → Vehicle Control History
How: export to Excel (disk icon) + screen capture
4. Individual trigger events, each one relevant
Where: event list → event → disk icon
How: export to Excel + screen capture
5. Software version & subscription expiration
Where: main screen at launch · How: screen capture
6. Interface (VIM) selection
Where: Setup → VIM Select · How: screen capture
7. Vehicle identification and VIN
Where: Vehicle Connection Wizard · How: screen capture
8. ECU inventory
Where: System Select tab · How: screen capture
9. Health Check report
Where: System Select → Health Check · How: save / print to PDF
10. SRS Airbag trouble codes
Where: SRS Airbag → Trouble Codes · How: save (disk icon) + screen capture
11. SRS Airbag data list
Where: SRS Airbag → Data List · How: save (disk icon) + screen capture
12. Consent notice as acknowledged
Where: Read Data (IMG_OPE_DDR-009) · How: screen capture
13. Image categories requested
Where: image selection screen · How: screen capture
14. Read-out estimated time
Where: Read Data (IMG_OPE_DDR-021) · How: screen capture
15. Scene photographs and clock note
Where: vehicle, VIN plate, odometer, DLC · How: camera / notes
Next, off the vehicle: load the .vdas file into PCS Data Viewer and run File → Output PCS Data for the CSV, image and PDF output. Do this before the TIS subscription expires — once it does, the .vdas file can no longer be opened. Those steps are in the full Toyota Techstream Imaging Guide.
